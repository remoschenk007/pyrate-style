# Pyrate-Style – Website

Brand website for Pyrate-Style, Hamburg. Leather and sterling silver, since 1984.

- `index.html` – homepage (vanilla HTML/CSS/JS, no build step)
- `img/` – photos and logo files
- `robots.txt`, `sitemap.xml`, `llms.txt` – search engines and AI search

The online shop runs on Shopify. Shop links currently point to the existing shop at pyratestyle.com until Shopify is live.

## Preview locally
Open `index.html` in the browser, or run `python3 -m http.server` in this folder and open http://localhost:8000.

## Before launch on pyratestyle.com
1. Replace the Instagram screenshots in `img/` with full-resolution photos.
2. Point the shop links to the Shopify store.
3. Add a `CNAME` file with `www.pyratestyle.com` and update DNS.
4. Set up redirects from the old Wix URLs.
